# 🛠️✨ Multi-Utility Toolkit

> 🐍 A simple and useful Python project that combines multiple utilities into one organized toolkit.

---

## 📌 About the Project

The **Multi-Utility Toolkit** is a Python-based project designed to perform different everyday programming tasks through separate modules.

The project is divided into multiple files, where each file handles a specific type of operation. This makes the project easier to understand, maintain, and use.

✨ The main goal of this project is to practice Python concepts such as **functions, modules, file handling, date and time operations, mathematical calculations, random data generation, and menu-driven programming**.

---

## 🎯 Project Purpose

The purpose of this project is to:

- 🧠 Improve Python programming knowledge
- 📦 Understand how modules work
- 🔢 Perform mathematical calculations
- 📅 Work with dates and time
- 📁 Learn file handling
- 🎲 Generate random values and data
- 🧩 Organize a large program into smaller modules
- 🖥️ Create a simple menu-driven application
- 🛠️ Practice error handling and user input

## 📂 Project Modules

### 🔵 1. Circle Tools
This module provides utilities related to circles.

**Main features:**
- 📐 Calculate the area of a circle
- 🔄 Calculate the circumference of a circle

---

### 🟢 2. Triangle Tools
This module performs basic triangle calculations.

**Main features:**
- 📐 Calculate the area of a triangle
- 📏 Calculate the perimeter of a triangle

---

### 🟠 3. Rectangle Tools
This module handles basic rectangle calculations.

**Main features:**
- 📐 Calculate the area of a rectangle
- 📏 Calculate the perimeter of a rectangle

---

### 🟣 4. Date Manager
This module is used for date-related operations.

**Main features:**
- 📅 Display the current date
- 🔄 Convert a date into another format
- 🧮 Calculate the number of days between two dates
- ⚠️ Handle invalid date formats

---

### 🟡 5. Document Manager
This module provides basic file operations.

**Main features:**
- 📄 Create a file
- ✍️ Write content into a file
- 👀 Read and display file content
- ➕ Add content to an existing file
- ⚠️ Handle missing files

---

### 🔴 6. Time Manager
This module focuses on date and time utilities.

**Main features:**
- 🕐 Display current date and time
- 📅 Format custom dates
- 🧮 Find the difference between dates
- ⏱️ Stopwatch functionality
- ⏳ Countdown functionality

---

### 🧮 7. Math Tools
This module performs different mathematical operations.

**Main features:**
- 🔢 Calculate factorial
- 💰 Calculate compound interest
- 📐 Perform trigonometric calculations
- 🔵 Find area of a circle
- 🟧 Find area of a rectangle
- 🔺 Find area of a triangle

---

### 🎲 8. Random Tools
This module is used to generate random data.

**Main features:**
- 🎯 Generate a random number
- 📋 Generate a random list
- 🔐 Generate a random password
- 🔢 Generate a random OTP

---

### 🗂️ 9. Main Module
The main module acts as the central part of the project.

It provides a menu through which the user can select different utilities and access the required module.

**Main responsibilities:**
- 🖥️ Display the main menu
- 📦 Import project modules
- 🔀 Navigate between different utilities
- 🔍 Explore module attributes
- 🆔 Generate UUID values
- 🚪 Provide an option to exit the application

---

## ⚙️ How the Project Works

The project follows a simple menu-driven workflow:

**👤 User → 🖥️ Main Menu → 📦 Select Module → ⚙️ Perform Operation → 📊 Display Result**

The user first opens the main program and selects an option. The selected module then performs the required operation and displays the result.
